# 🩺 CareSync

CareSync is a premium healthcare landing page inspired by modern medical technology platforms, delivering an elegant, responsive, and interactive experience for patients aged 45+ and healthcare professionals. The project combines a calming visual identity with AI-powered healthcare simulations, smart onboarding, and interactive medical management components.

---

## ✨ Features

### 🎨 Modern Healthcare Design

- Premium warm-neutral color palette
- Elegant typography using **Newsreader** and **Plus Jakarta Sans**
- Fully responsive layout (Desktop, Tablet, Mobile)
- Smooth animations and micro-interactions
- Accessibility-focused visual hierarchy

### 🚀 Hero Section

- Product rating badge
- Healthcare community statistics
- Interactive calorie tracking card
- Active senior lifestyle showcase
- Floating call-to-action buttons

### ⚡ Velocity Scroll

- Dynamic scrolling announcement banner
- Scroll speed adapts based on user interaction
- Smooth infinite marquee animation

### 📚 Sticky Overlapping Sections

Interactive stacked cards featuring:

- GPUs Infrastructure
- AI Inference
- About CareSync
- Healthcare Blog
- Documentation & API

Each section overlaps smoothly while ensuring all content remains readable before transitioning.
